# Profil Muhammad Arwan Maulana

Halaman profil sederhana yang dibuat menggunakan HTML, CSS, dan JavaScript.

## Menjalankan secara lokal

Buka `index.html` di browser. Tidak diperlukan proses build atau instalasi dependensi.

## Menerbitkan dengan GitHub Pages

1. Buat repository baru di GitHub.
2. Unggah `index.html`, `styles.css`, `script.js`, dan `README.md` ke repository.
3. Buka **Settings → Pages**, pilih branch utama dan folder root, lalu simpan.
